# 仕様衝突点リスト

要件定義書 Ver.20.0 (`~/Downloads/PDF書類/CLUB GALAXY 要件定義書.pdf`) と
指示書_CLUB_GALAXY_POS.md (`~/Downloads/CLUB-GALAXY/指示書_CLUB_GALAXY_POS.md`) の
矛盾点を記録します。

**原則**: 要件定義書 Ver.20.0 を正としつつ、明確に新しい仕様指示と判断できる箇所は指示書を採用。
衝突を残すことで先方と再確認できる形に。

## 備考

1. 給与計算は実店舗の運用に最も影響するため、指示書(先方指示に基づく)が信頼度高と判断。
2. 要件定義書の保証率ロジックは UI に参考表示として残し、先方が「やっぱり保証率必要」となった場合に復元しやすくしている。
3. バック額は「指示書は固定選択肢で簡潔化したい意図」と「要件定義書は柔軟性優先」の両立として、デフォルト値を指示書基準にし、管理画面で編集可を維持。
4. 消費税は両者とも内税扱いで一致しているため衝突なし(実装は2026-04-17に修正済)。
